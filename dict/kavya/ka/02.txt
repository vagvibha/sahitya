विहितां प्रियया मनःप्रियां अथ निश्चित्य गिरं गरीयसीम् ।
उपपत्तिमदूर्जिताश्रयं नृपं ऊचे वचनं वृकोदरः ॥२।१॥
====
+ e:KA-02-01
‹ <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-02">॥२।२॥</a> ›

यदवोचत वीक्ष्य मानिनी परितः स्नेहमयेन चक्षुषा ।
अपि वागधिपस्य दुर्वचं वचनं तद्विदधीत विस्मयं ॥२।२॥
====
+ e:KA-02-02
‹ <a href="bword://KA-02-01">॥२।१॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-03">॥२।३॥</a> ›

विषमोऽपि विगाह्यते नयः कृततीर्थः पयसां इवाशयः ।
स तु तत्र विशेषदुर्लभः सदुपन्यस्यति कृत्यवर्त्म यः ॥२।३॥
====
+ e:KA-02-03
‹ <a href="bword://KA-02-02">॥२।२॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-04">॥२।४॥</a> ›

परिणामसुखे गरीयसि व्यथकेऽस्मिन्वचसि क्षतौजसाम् ।
अतिवीर्यवतीव भेषजे बहुरल्पीयसि दृश्यते गुणः ॥२।४॥
====
+ e:KA-02-04
‹ <a href="bword://KA-02-03">॥२।३॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-05">॥२।५॥</a> ›

इयं इष्टगुणाय रोचतां रुचिरार्था भवतेऽपि भारती ।
ननु वक्तृविशेषनिःस्पृहा गुणगृह्या वचने विपश्चितः ॥२।५॥
====
+ e:KA-02-05
‹ <a href="bword://KA-02-04">॥२।४॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-06">॥२।६॥</a> ›

चतसृष्वपि ते विवेकिनी नृप विद्यासु निरूढिं आगता ।
कथं एत्य मतिर्विपर्ययं करिणी पङ्कं इवावसीदति ॥२।६॥
====
+ e:KA-02-06
‹ <a href="bword://KA-02-05">॥२।५॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-07">॥२।७॥</a> ›

विधुरं किं अतः परं परैरवगीतां गमिते दशां इमाम् ।
अवसीदति यत्सुरैरपि त्वयि सम्भावितवृत्ति पौरुषम् ॥२।७॥
====
+ e:KA-02-07
‹ <a href="bword://KA-02-06">॥२।६॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-08">॥२।८॥</a> ›

द्विषतां उदयः सुमेधसा गुरुरस्वन्ततरः सुमर्षणः ।
न महानपि भूतिं इच्छता फलसम्पत्प्रवणः परिक्षयः ॥२।८॥
====
+ e:KA-02-08
‹ <a href="bword://KA-02-07">॥२।७॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-09">॥२।९॥</a> ›

अचिरेण परस्य भूयसीं विपरीतां विगणय्य चात्मनः ।
क्षययुक्तिं उपेक्षते कृती कुरुते तत्प्रतिकारं अन्यथा ॥२।९॥
====
+ e:KA-02-09
‹ <a href="bword://KA-02-08">॥२।८॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-10">॥२।१०॥</a> ›

अनुपालयतां उदेष्यतीं प्रभुशक्तिं द्विषतां अनीहया ।
अपयान्त्यचिरान्महीभुजां जननिर्वादभयादिव श्रियः ॥२।१०॥
====
+ e:KA-02-10
‹ <a href="bword://KA-02-09">॥२।९॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-11">॥२।११॥</a> ›

क्षययुक्तं अपि स्वभावजं दधतं धाम शिवं समृद्धये ।
प्रणमन्त्यनपायं उत्थितं प्रतिपच्चन्द्रं इव प्रजा नृपम् ॥२।११॥
====
+ e:KA-02-11
‹ <a href="bword://KA-02-10">॥२।१०॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-12">॥२।१२॥</a> ›

प्रभवः खलु कोशदण्डयोः कृतपञ्चाङ्गविनिर्णयो नयः ।
स विधेयपदेषु दक्षतां नियतिं लोक इवानुरुध्यते ॥२।१२॥
====
+ e:KA-02-12
‹ <a href="bword://KA-02-11">॥२।११॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-13">॥२।१३॥</a> ›

अभिमानवतो मनस्विनः प्रियं उच्चैः पदं आरुरुक्षतः ।
विनिपातनिवर्तनक्षमं मतं आलम्बनं आत्मपौरुषम् ॥२।१३॥
====
+ e:KA-02-13
‹ <a href="bword://KA-02-12">॥२।१२॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-14">॥२।१४॥</a> ›

विपदोऽभिभवन्त्यविक्रमं रहयत्यापदुपेतं आयतिः ।
नियता लघुता निरायतेरगरीयान्न पदं नृपश्रियः ॥२।१४॥
====
+ e:KA-02-14
‹ <a href="bword://KA-02-13">॥२।१३॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-15">॥२।१५॥</a> ›

तदलं प्रतिपक्षं उन्नतेरवलम्ब्य व्यवसायवन्ध्यताम् ।
निवसन्ति पराक्रमाश्रया न विषादेन समं समृद्धयः ॥२।१५॥
====
+ e:KA-02-15
‹ <a href="bword://KA-02-14">॥२।१४॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-16">॥२।१६॥</a> ›

अथ चेदवधिः प्रतीक्ष्यते कथं आविष्कृतजिह्मवृत्तिना ।
धृतराष्ट्रसुतेन सुत्यज्याश्चिरं आस्वाद्य नरेन्द्रसम्पदः ॥२।१६॥
====
+ e:KA-02-16
‹ <a href="bword://KA-02-15">॥२।१५॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-17">॥२।१७॥</a> ›

द्विषता विहितं त्वयाथवा यदि लब्धा पुनरात्मनः पदम् ।
जननाथ तवानुजन्मनां कृतं आविष्कृतपौरुषैर्भुजैः ॥२।१७॥
====
+ e:KA-02-17
‹ <a href="bword://KA-02-16">॥२।१६॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-18">॥२।१८॥</a> ›

मदसिक्तमुखैर्मृगाधिपः करिभिर्वर्तयति स्वयं हतैः ।
लघयन्खलु तेजसा जगन्न महानिच्छति भूतिं अन्यतः ॥२।१८॥
====
+ e:KA-02-18
‹ <a href="bword://KA-02-17">॥२।१७॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-19">॥२।१९॥</a> ›

अभिमानधनस्य गत्वरैरसुभिः स्थास्नु यशश्चिचीषतः ।
अचिरांशुविलासचञ्चला ननु लक्ष्मीः फलं आनुषङ्गिकम् ॥२।१९॥
====
+ e:KA-02-19
‹ <a href="bword://KA-02-18">॥२।१८॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-20">॥२।२०॥</a> ›

ज्वलितं न हिरण्यरेतसं चयं आस्कन्दति भस्मनां जनः ।
अभिभूतिभयादसूनतः सुखं उज्झन्ति न धाम मानिनः ॥२।२०॥
====
+ e:KA-02-20
‹ <a href="bword://KA-02-19">॥२।१९॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-21">॥२।२१॥</a> ›

किं अवेक्ष्य फलं पयोधरान्ध्वनतः प्रार्थयते मृगाधिपः ।
प्रकृतिः खलु सा महीयसः सहते नान्यसमुन्नतिं यया ॥२।२१॥
====
+ e:KA-02-21
‹ <a href="bword://KA-02-20">॥२।२०॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-22">॥२।२२॥</a> ›

कुरु तन्मतिं एव विक्रमे नृप निर्धूय तमः प्रमादजम् ।
ध्रुवं एतदवेहि विद्विषां त्वदनुत्साहहता विपत्तयः ॥२।२२॥
====
+ e:KA-02-22
‹ <a href="bword://KA-02-21">॥२।२१॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-23">॥२।२३॥</a> ›

द्विरदानिव दिग्विभावितांश्चतुरस्तोयनिधीनिवायतः ।
प्रसहेत रणे तवानुजान्द्विषतां कः शतमन्युतेजसः ॥२।२३॥
====
+ e:KA-02-23
‹ <a href="bword://KA-02-22">॥२।२२॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-24">॥२।२४॥</a> ›

ज्वलतस्तव जातवेदसः सततं वैरिकृतस्य चेतसि ।
विदधातु शमं शिवेतरा रिपुनारीनयनाम्बुसन्ततिः ॥२।२४॥
====
+ e:KA-02-24
‹ <a href="bword://KA-02-23">॥२।२३॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-25">॥२।२५॥</a> ›

इति दर्शितविक्रियं सुतं मरुतः कोपपरीतमानसम् ।
उपसान्त्वयितुं महीपतिर्द्विरदं दुष्टं इवोपचक्रमे ॥२।२५॥
====
+ e:KA-02-25
‹ <a href="bword://KA-02-24">॥२।२४॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-26">॥२।२६॥</a> ›

अपवर्जितविप्लवे शुचय्हृदयग्राहिणि मङ्गलास्पदे ।
विमला तव विस्तरे गिरां मतिरादर्श इवाभिदृश्यते ॥२।२६॥
====
+ e:KA-02-26
‹ <a href="bword://KA-02-25">॥२।२५॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-27">॥२।२७॥</a> ›

स्फुटता न पदैरपाकृता न च न स्वीकृतं अर्थगौरवम् ।
रचिता पृथगर्थता गिरां न च सामर्थ्यं अपोहितं क्वचिथ् ॥२।२७॥
====
+ e:KA-02-27
‹ <a href="bword://KA-02-26">॥२।२६॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-28">॥२।२८॥</a> ›

उपपत्तिरुदाहृता बलादनुमानेन न चागमः क्षतः ।
इदं ईदृगनीदृगाशयः प्रसभं वक्तुं उपक्रमेत कः ॥२।२८॥
====
+ e:KA-02-28
‹ <a href="bword://KA-02-27">॥२।२७॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-29">॥२।२९॥</a> ›

अवितृप्ततया तथापि मे हृदयं निर्णयं एव धावति ।
अवसाययितुं क्षमाः सुखं न विधेयेषु विशेषसम्पदः ॥२।२९॥
====
+ e:KA-02-29
‹ <a href="bword://KA-02-28">॥२।२८॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-30">॥२।३०॥</a> ›

सहसा विदधीत न क्रियां अविवेकः परं आपदां पदम् ।
वृणते हि विमृश्यकारिणं गुणलुब्धाः स्वयं एव सम्पदः ॥२।३०॥
====
+ e:KA-02-30
‹ <a href="bword://KA-02-29">॥२।२९॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-31">॥२।३१॥</a> ›

अभिवर्षति योऽनुपालयन्विधिबीजानि विवेकवारिणा ।
स सदा फलशालिनीं क्रियां शरदं लोक इवाधितिष्ठति ॥२।३१॥
====
+ e:KA-02-31
‹ <a href="bword://KA-02-30">॥२।३०॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-32">॥२।३२॥</a> ›

शुचि भूषयति श्रुतं वपुः प्रशमस्तस्य भवत्यलंक्रिया ।
प्रशमाभरणं पराक्रमः स नयापादितसिद्धिभूषणः ॥२।३२॥
====
+ e:KA-02-32
‹ <a href="bword://KA-02-31">॥२।३१॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-33">॥२।३३॥</a> ›

मतिभेदतमस्तिरोहिते गहने कृत्यविधौ विवेकिनाम् ।
सुकृतः परिशुद्ध आगमः कुरुते दीप इवार्थदर्शनम् ॥२।३३॥
====
+ e:KA-02-33
‹ <a href="bword://KA-02-32">॥२।३२॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-34">॥२।३४॥</a> ›

स्पृहणीयगुणैर्महात्मभिश्चरिते वर्त्मनि यच्छतां मनः ।
विधिहेतुरहेतुरागसां विनिपातोऽपि समः समुन्नतेः ॥२।३४॥
====
+ e:KA-02-34
‹ <a href="bword://KA-02-33">॥२।३३॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-35">॥२।३५॥</a> ›

शिवं औपयिकं गरीयसीं फलनिष्पत्तिं अदूषितायतिम् ।
विगणय्य नयन्ति पौरुषं विजितक्रोधरया जिगीषवः ॥२।३५॥
====
+ e:KA-02-35
‹ <a href="bword://KA-02-34">॥२।३४॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-36">॥२।३६॥</a> ›

अपनेयं उदेतुं इच्छता तिमिरं रोषमयं धिया पुरः ।
अविभिद्य निशाकृतं तमः प्रभया नांशुमताप्युदीयते ॥२।३६॥
====
+ e:KA-02-36
‹ <a href="bword://KA-02-35">॥२।३५॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-37">॥२।३७॥</a> ›

बलवानपि कोपजन्मनस्तमसो नाभिभवं रुणद्धि यः ।
क्षयपक्ष इवैन्दवीः कलाः सकला हन्ति स शक्तिसम्पदः ॥२।३७॥
====
+ e:KA-02-37
‹ <a href="bword://KA-02-36">॥२।३६॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-38">॥२।३८॥</a> ›

समवृत्तिरुपैति मार्दवं समये यश्च तनोति तिग्मताम् ।
अधितिष्ठति लोकं ओजसा स विवस्वानिव मेदिनीपतिः ॥२।३८॥

क्व चिराय परिग्रहः श्रियां क्व च दुष्टेन्द्रियवाजिवश्यता ।
शरदभ्रचलाश्चलेन्द्रियैरसुरक्षा हि बहुच्छलाः श्रियः ॥२।३९॥
====

‹ <a href="bword://KA-02-38">॥२।३८॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-40">॥२।४०॥</a> ›

किं असामयिकं वितन्वता मनसः क्षोभं उपात्तरंहसः ।
क्रियते पतिरुच्चकैरपां भवता धीरतयाधरीकृतः ॥२।४०॥
====
+ e:KA-02-40
‹ <a href="bword://KA-02-39">॥२।३९॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-41">॥२।४१॥</a> ›

श्रुतं अप्यधिगम्य ये रिपून्विनयन्ते स्म न शरीरजन्मनः ।
जनयन्त्यचिराय सम्पदां अयशस्ते खलु चापलाश्रयम् ॥२।४१॥
====
+ e:KA-02-41
‹ <a href="bword://KA-02-40">॥२।४०॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-42">॥२।४२॥</a> ›

अतिपातितकालसाधना स्वशरीरेन्द्रियवर्गतापनी ।
जनवन्न भवन्तं अक्षमा नयसिद्धेरपनेतुं अर्हति ॥२।४२॥
====
+ e:KA-02-42
‹ <a href="bword://KA-02-41">॥२।४१॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-43">॥२।४३॥</a> ›

उपकारकं आयतेर्भृशं प्रसवः कर्मफलस्य भूरिणः ।
अनपायि निबर्हणं द्विषां न तितिक्षासमं अस्ति साधनम् ॥२।४३॥
====
+ e:KA-02-43
‹ <a href="bword://KA-02-42">॥२।४२॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-44">॥२।४४॥</a> ›

प्रणतिप्रवणान्विहाय नः सहजस्नेहनिबद्धचेतसः ।
प्रणमन्ति सदा सुयोधनं प्रथमे मानभृतां न वृष्णयः ॥२।४४॥
====
+ e:KA-02-44
‹ <a href="bword://KA-02-43">॥२।४३॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-45">॥२।४५॥</a> ›

सुहृदः सहजास्तथेतरे मतं एषां न विलङ्घयन्ति ये ।
विनयादिव यापयन्ति ते धृतराष्ट्रात्मजं आत्मसिद्धये ॥२।४५॥
====
+ e:KA-02-45
‹ <a href="bword://KA-02-44">॥२।४४॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-46">॥२।४६॥</a> ›

अभियोग इमान्महीभुजो भवता तस्य ततः कृतावधेः ।
प्रविघाटयिता समुत्पतन्हरिदश्वः कमलाकरानिव ॥२।४६॥
====
+ e:KA-02-46
‹ <a href="bword://KA-02-45">॥२।४५॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-47">॥२।४७॥</a> ›

उपजापसहान्विलङ्घयन्स विधाता नृपतीन्मदोद्धतः ।
सहते न जनोऽप्यधःक्रियां किं उ लोकाधिकधाम राजकम् ॥२।४७॥
====
+ e:KA-02-47
‹ <a href="bword://KA-02-46">॥२।४६॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-48">॥२।४८॥</a> ›

असमापितकृत्यसम्पदां हतवेगं विनयेन तावता ।
प्रभवन्त्यभिमानशालिनां मदं उत्तम्भयितुं विभूतयः ॥२।४८॥
====
+ e:KA-02-48
‹ <a href="bword://KA-02-47">॥२।४७॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-49">॥२।४९॥</a> ›

मदमानसमुद्धतं नृपं न वियुङ्क्ते नियमेन मूढता ।
अतिमूढ उदस्यते नयान्नयहीनादपरज्यते जनः ॥२।४९॥
====
+ e:KA-02-49
‹ <a href="bword://KA-02-48">॥२।४८॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-50">॥२।५०॥</a> ›

अपरागसमीरणेरितः क्रमशीर्णाकुलमूलसन्ततिः ।
सुकरस्तरुवत्सहिष्णुना रिपुरुन्मूलयितुं महानपि ॥२।५०॥
====
+ e:KA-02-50
‹ <a href="bword://KA-02-49">॥२।४९॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-51">॥२।५१॥</a> ›

अणुरप्युपहन्ति विग्रहः प्रभुं अन्तःप्रकृतिप्रकोपजः ।
अखिलं हि हिनस्ति भूधरं तरुशाखान्तनिघर्षजोऽनलः ॥२।५१॥
====
+ e:KA-02-51
‹ <a href="bword://KA-02-50">॥२।५०॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-52">॥२।५२॥</a> ›

मतिमान्विनयप्रमाथिनः समुपेक्षेत समुन्नतिं द्विषः ।
सुजयः खलु तादृगन्तरे विपदन्ता ह्यविनीतसम्पदः ॥२।५२॥
====
+ e:KA-02-52
‹ <a href="bword://KA-02-51">॥२।५१॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-53">॥२।५३॥</a> ›

लघुवृत्तितया भिदां गतं बहिरन्तश्च नृपस्य मण्डलम् ।
अभिभूय हरत्यनन्तरः शिथिलं कूलं इवापगारयः ॥२।५३॥
====
+ e:KA-02-53
‹ <a href="bword://KA-02-52">॥२।५२॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-54">॥२।५४॥</a> ›

अनुशासतं इत्यनाकुलं नयवर्त्माकुलं अर्जुनाग्रजम् ।
स्वयं अर्थ इवाभिवाञ्छितस्तं अभीयाय पराशरात्मजः ॥२।५४॥
====
+ e:KA-02-54
‹ <a href="bword://KA-02-53">॥२।५३॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-55">॥२।५५॥</a> ›

मधुरैरवशानि लम्भयन्नपि तिर्यञ्चि शमं निरीक्षितैः ।
परितः पटु बिभ्रदेनसां दहनं धाम विलोकनक्षमम् ॥२।५५॥
====

‹ <a href="bword://KA-02-54">॥२।५४॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-56">॥२।५६॥</a> ›

सहसोपगतः सविस्मयं तपसां सूतिरसूतिरेनसाम् ।
ददृशे जगतीभुजा मुनिः स वपुष्मानिव पुण्यसंचयः ॥२।५६॥
====

‹ <a href="bword://KA-02-55">॥२।५५॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-57">॥२।५७॥</a> ›

अथोच्चकैरासनतः परार्ध्यादुद्यन्स धूतारुणवल्कलाग्रः ।
रराज कीर्णाकपिशांशुजालः शृङ्गात्सुमेरोरिव तिग्मरश्मिः ॥२।५७॥
====

‹ <a href="bword://KA-02-56">॥२।५६॥</a> · <a href="bword://KA-02">KA-02</a> · <a href="bword://KA-02-58">॥२।५८॥</a> ›

अवहितहृदयो विधाय स अर्हां ऋषिवदृषिप्रवरे गुरूपदिष्टाम् ।
तदनुमतं अलंचकार पश्चात्प्रशम इव श्रुतं आसनं नरेन्द्रः ॥२।५८॥
====

व्यक्तोदितस्मितमयूखविभासितोष्ठस्तिष्ठन्मुनेरभिमुखं स विकीर्णधाम्नः ।
तन्वन्तं इद्धं अभितो गुरुं अंशुजालं लक्ष्मीं उवाह सकलस्य शशाङ्कमूर्तेः ॥२।५९॥
