### पाठः १ – मङ्गलाचरणम् { #p1 }

#### १.३ ग्रन्थारम्भोद्देशः { #p1-3 }

ग्रन्थारम्भे विघ्नविघाताय समुचितेष्टदेवतां ग्रन्थकृत् परामृशति –

#### १.४ मङ्गलपद्यम् { #p1-4 }

नियतिकृतनियमरहितां ह्लादैकमयीमनन्यपरतन्त्राम्।  
नवरसरुचिरां निर्मितिमादधती भारती कवेर्जयति ॥१॥

#### १.५ ब्रह्मनिर्मितिस्वरूपम् { #p1-5 }

नियतिशक्त्या नियतरूपा सुखदुःखमोहस्वभावा परमाण्वाद्युपादानकर्मादिसहकारिकारणपरतन्त्रा षड्रसा न च हृद्यैव तैः, तादृशी ब्रह्मणो निर्मितिर्निर्माणम्।

#### १.६ कविवाङ्निर्मितेः उत्कर्षः { #p1-6 }

एतद्विलक्षणा तु कविवाङ्निर्मितिः। अत एव जयति। जयत्यर्थेन च नमस्कार आक्षिप्यत इति तां प्रत्यस्मि प्रणत इति लभ्यते।

### पाठः २ – काव्यप्रयोजनम् { #p2 }

#### २.३ अभिधेयं सप्रयोजनम् { #p2-3 }

इहाभिधेयं सप्रयोजनमित्याह –

#### २.४ प्रयोजनकारिका { #p2-4 }

काव्यं यशसेऽर्थकृते व्यवहारविदे शिवेतरक्षतये।  
सद्यः परनिर्वृतये कान्तासम्मिततयोपदेशयुजे ॥२॥

#### २.५ सामान्यप्रयोजनानि { #p2-5 }

कालिदासादीनामिव यशः,

श्रीहर्षादेर्धावकादीनामिव धनम्,

राजादिगतोचिताचारपरिज्ञानम्,

आदित्यादेर्मयूरादीनामिवानर्थनिवारणम्,

#### २.६ मुख्यप्रयोजनम् { #p2-6 }

सकलप्रयोजनमौलिभूतं समनन्तरमेव रसास्वादनसमुद्भूतं विगलितवेद्यान्तरमानन्दम्,

#### २.७ उपदेशवैलक्षण्यम्, यथायोगम् { #p2-7 }

प्रभुसम्मितशब्दप्रधानवेदादिशास्त्रेभ्यः

सुहृत्सम्मितार्थतात्पर्यवत्पुराणादीतिहासेभ्यश्च

शब्दार्थयोर्गुणभावेन रसाङ्गभूतव्यापारप्रवणतया

विलक्षणं यत् काव्यं लोकोत्तरवर्णनानिपुणकविकर्म तत् कान्तेव सरसतापादनेनाभिमुखीकृत्य रामादिवद्वर्तितव्यं न रावणादिवदित्युपदेशं च

यथायोगं कवेः सहृदयस्य च करोतीति सर्वथा तत्र यतनीयम्॥

### पाठः ३ – काव्यकारणम् { #p3 }

#### ३.३ कारणकारिका { #p3-3 }

एवमस्य प्रयोजनमुक्त्वा कारणमाह –

शक्तिर्निपुणता लोकशास्त्रकाव्याद्यवेक्षणात्।  
काव्यज्ञशिक्षयाभ्यास इति हेतुस्तदुद्भवे ॥३॥

#### ३.४ शक्तिः { #p3-4 }

शक्तिः कवित्वबीजरूपः संस्कारविशेषः, यां विना काव्यं न प्रसरेत्, प्रसृतं वा उपहसनीयं स्यात्।

#### ३.५ निपुणता (व्युत्पत्तिः) { #p3-5 }

लोकस्य स्थावरजङ्गमात्मकलोकवृत्तस्य, शास्त्राणां छन्दोव्याकरणाभिधानकोशकलाचतुर्वर्गगजतुरगखड्गादिलक्षणग्रन्थानां, काव्यानां च महाकविसम्बन्धिनाम्, आदिग्रहणादितिहासादीनां च विमर्शनाद् व्युत्पत्तिः।

#### ३.६ अभ्यासः { #p3-6 }

काव्यं कर्तुं विचारयितुं च ये जानन्ति तदुपदेशेन करणे योजने च पौनःपुन्येन प्रवृत्तिः।

#### ३.७ हेतुर्न तु हेतवः { #p3-7 }

इति त्रयः समुदिताः, न तु व्यस्तास्तस्य काव्यस्योद्भवे निर्माणे समुल्लासे च हेतुर्न तु हेतवः॥

### पाठः ४ – काव्यस्वरूपम् { #p4 }

#### ४.४ काव्यलक्षणम् { #p4-4 }

एवमस्य कारणमुक्त्वा स्वरूपमाह –

तददोषौ शब्दार्थौ सगुणावनलङ्कृती पुनः क्वापि।

दोषगुणालङ्काराः वक्ष्यन्ते। क्वापीत्यनेनैतदाह – यत्सर्वत्र सालङ्कारौ, क्वचित्तु स्फुटालङ्कारविरहेऽपि न काव्यत्वहानिः। यथा –

#### ४.५ उदाहरणम् – यः कौमारहरः { #p4-5 }

यः कौमारहरः स एव हि वरस्ता एव चैत्रक्षपा-  
स्ते चोन्मीलितमालतीसुरभयः प्रौढाः कदम्बानिलाः।  
सा चैवास्मि तथापि तत्र सुरतव्यापारलीलाविधौ  
रेवारोधसि वेतसीतरुतले चेतः समुत्कण्ठते ॥१॥

अत्र स्फुटो न कश्चिदलङ्कारः।

रसस्य च प्राधान्यान्नालङ्कारता।

### पाठः ५ – काव्यभेदाः { #p5 }

#### ५.३ उत्तमम् (ध्वनिः) { #p5-3 }

तद्भेदान् क्रमेणाह –

इदमुत्तममतिशयिनि व्यङ्ग्ये वाच्याद्ध्वनिर्बुधैः कथितः ॥४॥

इदमिति काव्यम्। बुधैर्वैयाकरणैः प्रधानभूतस्फोटरूपव्यङ्ग्यव्यञ्जकस्य शब्दस्य ध्वनिरिति व्यवहारः कृतः।

ततस्तन्मतानुसारिभिरन्यैरपि न्यग्भावितवाच्यव्यङ्ग्यव्यञ्जनक्षमस्य शब्दार्थयुगलस्य।

#### ५.४ उत्तमकाव्योदाहरणम् { #p5-4 }

यथा –

निःशेषच्युतचन्दनं स्तनतटं निर्मृष्टरागोऽधरो  
नेत्रे दूरमनञ्जने पुलकिता तन्वी तवेयं तनुः।  
मिथ्यावादिनि दूति बान्धवजनस्याज्ञातपीडागमे  
वापीं स्नातुमितो गतासि न पुनस्तस्याधमस्यान्तिकम् ॥२॥

अत्र तदन्तिकमेव रन्तुं गतासीति प्राधान्येनाधमपदेन व्यज्यते।

#### ५.५ मध्यमम् (गुणीभूतव्यङ्ग्यम्) { #p5-5 }

अतादृशि गुणीभूतव्यङ्ग्यं व्यङ्ग्ये तु मध्यमम्।

अतादृशि वाच्यादनतिशयिनि। यथा –

ग्रामतरुणं तरुण्या नववञ्जुलमञ्जरीसनाथकरम्।  
पश्यन्त्या भवति मुहुर्नितरां मलिना मुखच्छाया ॥३॥

अत्र वञ्जुललतागृहे दत्तसंकेता नागतेति व्यङ्ग्यं गुणीभूतं, तदपेक्षया वाच्यस्यैव चमत्कारित्वात्।

#### ५.६ अवरम् (चित्रम्) { #p5-6 }

शब्दचित्रं वाच्यचित्रमव्यङ्ग्यं त्ववरं स्मृतम् ॥५॥

चित्रमिति गुणालङ्कारयुक्तम्। अव्यङ्ग्यमिति स्फुटप्रतीयमानार्थरहितम्। अवरमधमम्। यथा –

स्वच्छन्दोच्छलदच्छकच्छकुहरच्छातेतराम्बुच्छटा-  
मूर्छन्मोहमहर्षिहर्षविहितस्नानाह्निकाह्नाय वः।  
भिद्यादुद्यदुदारदर्दुरदरीदीर्घादरिद्रद्रुम-  
द्रोहोद्रेकमहोर्मिमेदुरमदा मन्दाकिनी मन्दताम् ॥४॥

विनिर्गतं मानदमात्ममन्दिराद्भवत्युपश्रुत्य यदृच्छयापि यम्।  
ससंभ्रमेन्द्रद्रुतपातितार्गला निमीलिताक्षीव भियामरावती ॥५॥

इति काव्यप्रकाशे काव्यस्य प्रयोजनकारणस्वरूपविशेषनिर्णयो नाम प्रथम उल्लासः॥

### पाठः ६ – शब्दार्थस्वरूपम् { #p6 }

#### ६.३ शब्दार्थभेदाः { #p6-3 }

क्रमेण शब्दार्थयोः स्वरूपमाह –

[सू० ५] स्याद्वाचको लाक्षणिकः शब्दोऽत्र व्यञ्जकस्त्रिधा।

अत्रेति काव्ये। एषां स्वरूपं वक्ष्यते।

[सू० ६] वाच्यादयस्तदर्थाः स्युः

वाच्यलक्ष्यव्यङ्ग्याः।

[सू० ७] तात्पर्यार्थोऽपि केषुचित् ॥६॥

आकाङ्क्षायोग्यतासन्निधिवशाद्वक्ष्यमाणस्वरूपाणां पदार्थानां समन्वये तात्पर्यार्थो विशेषवपुरपदार्थोऽपि वाक्यार्थः समुल्लसतीत्यभिहितान्वयवादिनां मतम्।

वाच्य एव वाक्यार्थ इत्यन्विताभिधानवादिनः।

#### ६.४ अर्थानां व्यञ्जकत्वम् { #p6-4 }

[सू० ८] सर्वेषां प्रायशोऽर्थानां व्यञ्जकत्वमपीष्यते।

तत्र वाच्यस्य यथा –

मातर्गृहोपकरणमद्य खलु नास्तीति साधितं त्वया।  
तद्भण किं करणीयमेवमेव न वासरः स्थायी ॥६॥

अत्र स्वैरविहारार्थिनीति व्यज्यते।

लक्ष्यस्य यथा –

साधयन्ती सखि सुभगं क्षणे क्षणे दूनासि मत्कृते।  
सद्भावस्नेहकरणीयसदृशकं तावद्विरचितं त्वया ॥७॥

अत्र मत्प्रियं रमयन्त्या त्वया शत्रुत्वमाचरितमिति लक्ष्यं, तेन च कामुकविषयं सापराधत्वप्रकाशनं व्यङ्ग्यम्।

व्यङ्ग्यस्य यथा –

पश्य निश्चलनिष्पन्दा बिसिनीपत्रे राजते बलाका।  
निर्मलमरकतभाजनपरिस्थिता शङ्खशुक्तिरिव ॥८॥

अत्र निष्पन्दत्वेन आश्वस्तत्वं, तेन च जनरहितत्वम्, अतः सङ्केतस्थानमेतदिति कयाचित्कञ्चित्प्रत्युच्यते। अथवा मिथ्या वदसि न त्वमत्रागतोऽभूरिति व्यज्यते।

### पाठः ७ – वाचकस्वरूपम् { #p7 }

#### ७.३ वाचकलक्षणम् { #p7-3 }

वाचकादीनां क्रमेण स्वरूपमाह –

[सू० ९] साक्षात्सङ्केतितं योऽर्थमभिधत्ते स वाचकः ॥७॥

इहागृहीतसङ्केतस्य शब्दस्यार्थप्रतीतेरभावात्सङ्केतसहाय एव शब्दोऽर्थविशेषं प्रतिपादयतीति यस्य यत्राव्यवधानेन सङ्केतो गृह्यते स तस्य वाचकः।

#### ७.४ सङ्केतग्रहविषयाः (उपाधयः) { #p7-4 }

[सू० १०] सङ्केतितश्चतुर्भेदो जात्यादिर्जातिरेव वा।

यद्यप्यर्थक्रियाकारितया प्रवृत्तिनिवृत्तियोग्या व्यक्तिरेव, तथाप्यानन्त्याद्व्यभिचाराच्च तत्र सङ्केतः कर्तुं न युज्यत इति ‘गौः शुक्लश्चलो डित्थः’ इत्यादीनां विषयविभागो न प्राप्नोतीति च तदुपाधावेव सङ्केतः।

उपाधिश्च द्विविधः – वस्तुधर्मो वक्तृयदृच्छासन्निवेशितश्च। वस्तुधर्मोऽपि द्विविधः – सिद्धः साध्यश्च। सिद्धोऽपि द्विविधः – पदार्थस्य प्राणप्रदो विशेषाधानहेतुश्च।

तत्राद्यो जातिः। उक्तं हि वाक्यपदीये – ‘न हि गौः स्वरूपेण गौर्नाप्यगौः, गोत्वाभिसम्बन्धात्तु गौः’ इति।

द्वितीयो गुणः। शुक्लादिना हि लब्धसत्ताकं वस्तु विशिष्यते।

साध्यः पूर्वापरीभूतावयवः क्रियारूपः।

डित्थादिशब्दानामन्त्यबुद्धिनिर्ग्राह्यं संहृतक्रमं स्वरूपं वक्त्रा यदृच्छया डित्थादिष्वर्थेषूपाधित्वेन सन्निवेश्यत इति सोऽयं संज्ञारूपो यदृच्छात्मक इति।

#### ७.५ शास्त्रान्तरसम्मतिः { #p7-5 }

‘गौः शुक्लश्चलो डित्थः’ इत्यादौ चतुष्टयी शब्दानां प्रवृत्तिरिति महाभाष्यकारः।

परमाण्वादीनां तु गुणमध्यपाठात् पारिभाषिकं गुणत्वम्।

गुणक्रियायदृच्छानां वस्तुत एकरूपाणामप्याश्रयभेदाद्भेद इव लक्ष्यते, यथैकस्य मुखस्य खड्गमुकुरतैलाद्यालम्बनभेदात्।

#### ७.६ पूर्वमीमांसकमतम् { #p7-6 }

हिमपयःशङ्खाद्याश्रयेषु परमार्थतो भिन्नेषु शुक्लादिषु यद्वशेन शुक्लः शुक्ल इत्याद्यभिन्नाभिधानप्रत्ययोत्पत्तिस्तच्छुक्लत्वादि सामान्यम्।

गुडतण्डुलादिपाकादिष्वेवमेव पाकत्वादि।

बालवृद्धशुकाद्युदीरितेषु डित्थादिशब्देषु च प्रतिक्षणं भिद्यमानेषु डित्थाद्यर्थेषु वा डित्थत्वाद्यस्तीति

सर्वेषां शब्दानां जातिरेव प्रवृत्तिनिमित्तमित्यन्ये।

#### ७.७ मतान्तराणि { #p7-7 }

तद्वानपोहो वा शब्दार्थः कैश्चिदुक्त इति ग्रन्थगौरवभयात् प्रकृतानुपयोगाच्च न दर्शितम्।

#### ७.८ अभिधा { #p7-8 }

[सू० ११] स मुख्योऽर्थस्तत्र मुख्यो व्यापारोऽस्याभिधोच्यते ॥८॥

स इति साक्षात्सङ्केतितः। अस्येति शब्दस्य।

### पाठः ८ – शब्दस्य द्वितीयव्यापारः लक्षणा { #p8 }

#### ८.३ लक्षणालक्षणम् { #p8-3 }

[सू० १२] मुख्यार्थबाधे तद्योगे रूढितोऽथ प्रयोजनात्।  
अन्योऽर्थो लक्ष्यते यत्सा लक्षणारोपिता क्रिया ॥९॥

#### ८.४ उदाहरणे (रूढिः प्रयोजनं च) { #p8-4 }

‘कर्मणि कुशलः’ इत्यादौ दर्भग्रहणाद्ययोगात्, ‘गङ्गायां घोषः’ इत्यादौ च गङ्गादीनां घोषाद्याधारत्वासम्भवात् मुख्यार्थस्य बाधे, विवेचकत्वादौ सामीप्ये च सम्बन्धे, रूढितः प्रसिद्धेः, तथा ‘गङ्गातटे घोषः’ इत्यादेः प्रयोगात् येषां न तथा प्रतिपत्तिः तेषां पावनत्वादीनां धर्माणां तथाप्रतिपादनात्मनः प्रयोजनाच्च मुख्येनामुख्योऽर्थो लक्ष्यते यत्

#### ८.५ आरोपिता क्रिया { #p8-5 }

स आरोपितः शब्दव्यापारः सान्तरार्थनिष्ठो लक्षणा।

### पाठः ९ – लक्षणाभेदाः { #p9 }

#### ९.३ शुद्धा लक्षणा (उपादानम्, लक्षणम्) { #p9-3 }

[सू० १३] स्वसिद्धये पराक्षेपः परार्थं स्वसमर्पणम्।  
उपादानं लक्षणं चेत्युक्ता शुद्धैव सा द्विधा ॥१०॥

‘कुन्ताः प्रविशन्ति’, ‘यष्टयः प्रविशन्ति’ इत्यादौ कुन्तादिभिरात्मनः प्रवेशसिद्ध्यर्थं स्वसंयोगिनः पुरुषा आक्षिप्यन्ते। तत उपादानेनेयं लक्षणा।

‘गौरनुबन्ध्यः’ इत्यादौ श्रुतिचोदितमनुबन्धनं कथं मे स्यादिति जात्या व्यक्तिराक्षिप्यते, न तु शब्देनोच्यते, ‘विशेष्यं नाभिधा गच्छेत् क्षीणशक्तिर्विशेषणे’ इति न्यायादित्युपादानलक्षणा तु नोदाहर्तव्या। न ह्यत्र प्रयोजनमस्ति, न वा रूढिरियम्। व्यक्त्यविनाभावित्वात्तु जात्या व्यक्तिराक्षिप्यते, यथा ‘क्रियताम्’ इत्यत्र कर्ता, ‘कुरु’ इत्यत्र कर्म, ‘प्रविश’, ‘पिण्डीम्’ इत्यादौ गृहं भक्षयेत्यादि च।

‘पीनो देवदत्तो दिवा न भुङ्क्ते’ इत्यत्र च रात्रिभोजनं न लक्ष्यते, श्रुतार्थापत्तेरर्थापत्तेर्वा तस्य विषयत्वात्।

‘गङ्गायां घोषः’ इत्यत्र तटस्य घोषाधिकरणत्वसिद्धये गङ्गाशब्दः स्वार्थमर्पयति, इत्येवमादौ लक्षणेनैषा लक्षणा।

उभयरूपा चेयं शुद्धा, उपचारेणामिश्रितत्वात्।

#### ९.४ मुकुलमतखण्डनम् { #p9-4 }

अनयोर्लक्ष्यस्य लक्षकस्य च न भेदरूपं ताटस्थ्यम्। तटादीनां गङ्गादिशब्दैः प्रतिपादने तत्त्वप्रतिपत्तौ हि प्रतिपिपादयिषितप्रयोजनसम्प्रत्ययः। गङ्गासम्बन्धमात्रप्रतीतौ तु ‘गङ्गातटे घोषः’ इति मुख्यशब्दाभिधानाल्लक्षणायाः को भेदः।

#### ९.५ सारोपा साध्यवसाना च { #p9-5 }

[सू० १४] सारोपान्या तु यत्रोक्तौ विषयी विषयस्तथा।

आरोप्यमाण आरोपविषयश्च यत्रानपह्नुतभेदौ सामानाधिकरण्येन निर्दिश्येते सा लक्षणा सारोपा।

[सू० १५] विषय्यन्तःकृतेऽन्यस्मिन् सा स्यात्साध्यवसानिका ॥११॥

विषयिणाऽऽरोप्यमाणेनान्तःकृते निगीर्णेऽन्यस्मिन्नारोपविषये सति साध्यवसाना स्यात्।

[सू० १६] भेदाविमौ च सादृश्यात्सम्बन्धान्तरतस्तथा।  
गौणौ शुद्धौ च विज्ञेयौ

इमावारोपाध्यवसानरूपौ सादृश्यहेतू भेदौ ‘गौर्वाहीकः’ इत्यत्र ‘गौरयम्’ इत्यत्र च।

#### ९.६ गौर्वाहीकः – मतत्रयम् { #p9-6 }

अत्र हि स्वार्थसहचारिणो गुणा जाड्यमान्द्यादयो लक्ष्यमाणा अपि गोशब्दस्य परार्थाभिधाने प्रवृत्तिनिमित्तत्वमुपयान्ति, इति केचित्।

स्वार्थसहचारिगुणाभेदेन परार्थगता गुणा एव लक्ष्यन्ते, न तु परार्थोऽभिधीयते, इत्यन्ये।

साधारणगुणाश्रयत्वेन परार्थ एव लक्ष्यते, इत्यपरे।

#### ९.७ अविनाभावः { #p9-7 }

उक्तं चान्यत्र –

अभिधेयाविनाभूतप्रतीतिर्लक्षणोच्यते।  
लक्ष्यमाणगुणैर्योगाद्वृत्तेरिष्टा तु गौणता॥

इति।

अविनाभावोऽत्र सम्बन्धमात्रं, न तु नान्तरीयकत्वम्। तत्त्वे हि ‘मञ्चाः क्रोशन्ति’ इत्यादौ न लक्षणा स्यात्। अविनाभावे चाक्षेपेणैव सिद्धेर्लक्षणाया नोपयोग इत्युक्तम्।

#### ९.८ सम्बन्धाः, प्रयोजनानि, षड्भेदाः { #p9-8 }

‘आयुर्घृतम्’, ‘आयुरेवेदम्’ इत्यादौ च सादृश्यादन्यत् कार्यकारणभावादि सम्बन्धान्तरम्। एवमादौ च कार्यकारणभावादिलक्षणपूर्वे आरोपाध्यवसाने।

शुद्धभेदयोस्त्वन्यवैलक्षण्येनाव्यभिचारेण च कार्यकारित्वादि (प्रयोजनम्)।

अत्र गौणभेदयोर्भेदेऽपि ताद्रूप्यप्रतीतिः सर्वथैवाभेदावगमश्च प्रयोजनम्।

क्वचित्तादर्थ्यादुपचारः, यथा – इन्द्रार्था स्थूणा इन्द्रः। क्वचित् स्वस्वामिभावात्, यथा – राजकीयः पुरुषो राजा। क्वचिदवयवावयविभावात्, यथा – अग्रहस्त इत्यत्राग्रमात्रेऽवयवे हस्तः। क्वचित्तात्कर्म्यात्, यथा – अतक्षा तक्षा।

[सू० १७] लक्षणा तेन षड्विधा ॥१२॥

आद्यभेदाभ्यां सह।
