### पाठः १ – मङ्गलाचरणम् { #p1 }

#### १.३ ग्रन्थारम्भोद्देशः { #p1-3 }

ग्रन्थारम्भे विघ्नविघाताय समुचितेष्टदेवतां ग्रन्थकृत् परामृशति –

#### १.४ मङ्गलपद्यम् { #p1-4 }

नियतिकृतनियमरहितां ह्लादैकमयीमनन्यपरतन्त्राम्।  
नवरसरुचिरां निर्मितिमादधती भारती कवेर्जयति ॥१॥

#### १.५ ब्रह्मनिर्मितिस्वरूपम् { #p1-5 }

नियतिशक्त्या नियतरूपा सुखदुःखमोहस्वभावा परमाण्वाद्युपादानकर्मादिसहकारिकारणपरतन्त्रा षड्रसा न च हृद्यैव तैः, तादृशी ब्रह्मणो निर्मितिर्निर्माणम्।

#### १.६ कविवाङ्निर्मितेः उत्कर्षः { #p1-6 }

एतद्विलक्षणा तु कविवाङ्निर्मितिः। अत एव जयति। जयत्यर्थेन च नमस्कार आक्षिप्यत इति तां प्रत्यस्मि प्रणत इति लभ्यते।

### पाठः २ – काव्यप्रयोजनम् { #p2 }

#### २.३ अभिधेयं सप्रयोजनम् { #p2-3 }

इहाभिधेयं सप्रयोजनमित्याह –

#### २.४ प्रयोजनकारिका { #p2-4 }

काव्यं यशसेऽर्थकृते व्यवहारविदे शिवेतरक्षतये।  
सद्यः परनिर्वृतये कान्तासम्मिततयोपदेशयुजे ॥२॥

#### २.५ सामान्यप्रयोजनानि { #p2-5 }

कालिदासादीनामिव यशः,

श्रीहर्षादेर्धावकादीनामिव धनम्,

राजादिगतोचिताचारपरिज्ञानम्,

आदित्यादेर्मयूरादीनामिवानर्थनिवारणम्,

#### २.६ मुख्यप्रयोजनम् { #p2-6 }

सकलप्रयोजनमौलिभूतं समनन्तरमेव रसास्वादनसमुद्भूतं विगलितवेद्यान्तरमानन्दम्,

#### २.७ उपदेशवैलक्षण्यम्, यथायोगम् { #p2-7 }

प्रभुसम्मितशब्दप्रधानवेदादिशास्त्रेभ्यः

सुहृत्सम्मितार्थतात्पर्यवत्पुराणादीतिहासेभ्यश्च

शब्दार्थयोर्गुणभावेन रसाङ्गभूतव्यापारप्रवणतया

विलक्षणं यत् काव्यं लोकोत्तरवर्णनानिपुणकविकर्म तत् कान्तेव सरसतापादनेनाभिमुखीकृत्य रामादिवद्वर्तितव्यं न रावणादिवदित्युपदेशं च

यथायोगं कवेः सहृदयस्य च करोतीति सर्वथा तत्र यतनीयम्॥

### पाठः ३ – काव्यकारणम् { #p3 }

#### ३.३ कारणकारिका { #p3-3 }

एवमस्य प्रयोजनमुक्त्वा कारणमाह –

शक्तिर्निपुणता लोकशास्त्रकाव्याद्यवेक्षणात्।  
काव्यज्ञशिक्षयाभ्यास इति हेतुस्तदुद्भवे ॥३॥

#### ३.४ शक्तिः { #p3-4 }

शक्तिः कवित्वबीजरूपः संस्कारविशेषः, यां विना काव्यं न प्रसरेत्, प्रसृतं वा उपहसनीयं स्यात्।

#### ३.५ निपुणता (व्युत्पत्तिः) { #p3-5 }

लोकस्य स्थावरजङ्गमात्मकलोकवृत्तस्य, शास्त्राणां छन्दोव्याकरणाभिधानकोशकलाचतुर्वर्गगजतुरगखड्गादिलक्षणग्रन्थानां, काव्यानां च महाकविसम्बन्धिनाम्, आदिग्रहणादितिहासादीनां च विमर्शनाद् व्युत्पत्तिः।

#### ३.६ अभ्यासः { #p3-6 }

काव्यं कर्तुं विचारयितुं च ये जानन्ति तदुपदेशेन करणे योजने च पौनःपुन्येन प्रवृत्तिः।

#### ३.७ हेतुर्न तु हेतवः { #p3-7 }

इति त्रयः समुदिताः, न तु व्यस्तास्तस्य काव्यस्योद्भवे निर्माणे समुल्लासे च हेतुर्न तु हेतवः॥

### पाठः ४ – काव्यस्वरूपम् { #p4 }

#### ४.४ काव्यलक्षणम् { #p4-4 }

एवमस्य कारणमुक्त्वा स्वरूपमाह –

तददोषौ शब्दार्थौ सगुणावनलङ्कृती पुनः क्वापि।

दोषगुणालङ्काराः वक्ष्यन्ते। क्वापीत्यनेनैतदाह – यत्सर्वत्र सालङ्कारौ, क्वचित्तु स्फुटालङ्कारविरहेऽपि न काव्यत्वहानिः। यथा –

#### ४.५ उदाहरणम् – यः कौमारहरः { #p4-5 }

यः कौमारहरः स एव हि वरस्ता एव चैत्रक्षपा-  
स्ते चोन्मीलितमालतीसुरभयः प्रौढाः कदम्बानिलाः।  
सा चैवास्मि तथापि तत्र सुरतव्यापारलीलाविधौ  
रेवारोधसि वेतसीतरुतले चेतः समुत्कण्ठते ॥१॥

अत्र स्फुटो न कश्चिदलङ्कारः।

रसस्य च प्राधान्यान्नालङ्कारता।

### पाठः ५ – काव्यभेदाः { #p5 }

#### ५.३ उत्तमम् (ध्वनिः) { #p5-3 }

तद्भेदान् क्रमेणाह –

इदमुत्तममतिशयिनि व्यङ्ग्ये वाच्याद्ध्वनिर्बुधैः कथितः ॥४॥

इदमिति काव्यम्। बुधैर्वैयाकरणैः प्रधानभूतस्फोटरूपव्यङ्ग्यव्यञ्जकस्य शब्दस्य ध्वनिरिति व्यवहारः कृतः।

ततस्तन्मतानुसारिभिरन्यैरपि न्यग्भावितवाच्यव्यङ्ग्यव्यञ्जनक्षमस्य शब्दार्थयुगलस्य।

#### ५.४ उत्तमकाव्योदाहरणम् { #p5-4 }

यथा –

निःशेषच्युतचन्दनं स्तनतटं निर्मृष्टरागोऽधरो  
नेत्रे दूरमनञ्जने पुलकिता तन्वी तवेयं तनुः।  
मिथ्यावादिनि दूति बान्धवजनस्याज्ञातपीडागमे  
वापीं स्नातुमितो गतासि न पुनस्तस्याधमस्यान्तिकम् ॥२॥

अत्र तदन्तिकमेव रन्तुं गतासीति प्राधान्येनाधमपदेन व्यज्यते।

#### ५.५ मध्यमम् (गुणीभूतव्यङ्ग्यम्) { #p5-5 }

अतादृशि गुणीभूतव्यङ्ग्यं व्यङ्ग्ये तु मध्यमम्।

अतादृशि वाच्यादनतिशयिनि। यथा –

ग्रामतरुणं तरुण्या नववञ्जुलमञ्जरीसनाथकरम्।  
पश्यन्त्या भवति मुहुर्नितरां मलिना मुखच्छाया ॥३॥

अत्र वञ्जुललतागृहे दत्तसंकेता नागतेति व्यङ्ग्यं गुणीभूतं, तदपेक्षया वाच्यस्यैव चमत्कारित्वात्।

#### ५.६ अवरम् (चित्रम्) { #p5-6 }

शब्दचित्रं वाच्यचित्रमव्यङ्ग्यं त्ववरं स्मृतम् ॥५॥

चित्रमिति गुणालङ्कारयुक्तम्। अव्यङ्ग्यमिति स्फुटप्रतीयमानार्थरहितम्। अवरमधमम्। यथा –

स्वच्छन्दोच्छलदच्छकच्छकुहरच्छातेतराम्बुच्छटा-  
मूर्छन्मोहमहर्षिहर्षविहितस्नानाह्निकाह्नाय वः।  
भिद्यादुद्यदुदारदर्दुरदरीदीर्घादरिद्रद्रुम-  
द्रोहोद्रेकमहोर्मिमेदुरमदा मन्दाकिनी मन्दताम् ॥४॥

विनिर्गतं मानदमात्ममन्दिराद्भवत्युपश्रुत्य यदृच्छयापि यम्।  
ससंभ्रमेन्द्रद्रुतपातितार्गला निमीलिताक्षीव भियामरावती ॥५॥

इति काव्यप्रकाशे काव्यस्य प्रयोजनकारणस्वरूपविशेषनिर्णयो नाम प्रथम उल्लासः॥
